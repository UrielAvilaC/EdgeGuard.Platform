# Decisiones de arquitectura (ADR)

Cada decisión arquitectónica significativa se documenta como `ADR-NNN-slug.md`, numerada
correlativamente y sin huecos. Formato, en este orden: Contexto · Decisión · Justificación ·
Implicaciones · Estado · Fecha, más los campos de trazabilidad al pie.

Estados: `propuesta` → `aceptada` → `reemplazada (ADR-NNN)`. Una ADR `propuesta` se edita
libremente; una `aceptada` no se edita: se supera con una ADR nueva que la referencia.
